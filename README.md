Pucket Wallet is an AI-powered cryptocurrency wallet application built with React Native. It enables users to perform all wallet operations—including swaps, sending, receiving, and selling cryptocurrencies—through natural language interaction via text or voice commands in a chat interface. The project combines an intuitive user experience with advanced AI capabilities to simplify cryptocurrency transactions.

> Main Function Points
AI-powered chat interface for cryptocurrency transactions
Support for swap, send, receive, and sell operations via natural language
Voice and text command processing
Cryptocurrency wallet management
User-friendly interface design
Backend integration for transaction processing
> Technology Stack
React Native (frontend framework)
TypeScript (98.5% of codebase)
JavaScript (1.5% of codebase)
AWS (cloud services)
React ecosystem
